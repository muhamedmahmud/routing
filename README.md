# 🧭 React Routing Demo

A simple multi-page React application that demonstrates the use of **React Router** for client-side routing. The project uses **React**, **React Router DOM**, and **Bootstrap 5** to create a clean navigation experience between different pages without full page reloads.

---

## 📸 Demo

🌐 [Live Demo](https://routing-nine-liard.vercel.app/)  
📂 [GitHub Repository](https://github.com/muhamedmahmud/routing)

---

## 🚀 Features

- 🧭 Client-side routing with **React Router DOM**
- 🏠 Home, About, and NotFound pages  
- 🔄 Navigation without page reload  
- 📱 Responsive design with **Bootstrap 5**
- 🔗 Active link highlighting in the navbar

---

## 🛠️ Technologies Used

| Technology         | Description                             |
|--------------------|-----------------------------------------|
| React              | Front-end UI library                    |
| React Router DOM   | Routing between pages                   |
| Bootstrap 5        | Responsive design and layout styling    |
| JSX                | UI components structure and templating  |
| JavaScript (ES6+)  | Component logic and behavior            |
